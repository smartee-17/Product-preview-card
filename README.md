## Overview

This project is a responsive **Product Preview Card Component**, built as part of a Frontend Mentor challenge. The goal was to recreate a clean product card layout that adapts smoothly between mobile and desktop views, while keeping the HTML semantic and the CSS scalable.

A small JavaScript file is used to dynamically apply border-radius utility classes depending on the screen size, ensuring the card corners behave correctly on both mobile and desktop layouts.

### The challenge

Users should be able to:

- View the optimal layout depending on their device’s screen size

- See a responsive product image that switches between mobile and desktop versions

- Experience consistent spacing, typography, and visual hierarchy across breakpoints

- See hover and focus states for interactive elements

## My process

### Built with

- Modern CSS (CSS Variables, @layer, media queries)

- Flexbox for layout

- Mobile-first responsive design

- Vanilla JavaScript (for conditional class handling)


### What I learned

This project helped reinforce several important frontend concepts:

- How to structure CSS using ```@layer``` for better organization and scalability

- Effective use of CSS custom properties to control typography, spacing, colors, and layout from a single source

- Managing responsive background images using CSS variables

- Separating layout logic (CSS) from behavioral tweaks (JavaScript)

A key takeaway was realizing that not all responsive problems should be solved purely in CSS. In this case, JavaScript provided a clean way to toggle border-radius classes without duplicating styles or overcomplicating media queries


### Continued development

In future projects, I plan to:
